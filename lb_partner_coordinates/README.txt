Partner Latitude and Longitude — Odoo 18

Adds two Float fields to res.partner:
  - latitude
  - longitude

The fields are displayed on the Contact form after the VAT field.

Installation:
1. Extract the lb_partner_coordinates folder into your custom addons directory.
2. Restart the Odoo 18 service.
3. Enable Developer Mode and update the Apps List.
4. Search for "Partner Latitude and Longitude" and install it.

If Odoo does not show the module, verify that the module folder is inside
an addons path configured in odoo.conf.
